# ML Fundamentals

This folder contains the foundational machine learning topics for AI Engineer interview preparation.

Each topic includes:
- Definition
- Why it is needed
- Working
- Mermaid diagrams
- Interview answers
- Examples
- Common mistakes
- Revision notes

Planned topics include AI vs ML vs DL, supervised learning, unsupervised learning, regression, classification, overfitting, bias-variance, feature engineering, activation functions, optimizers, loss functions, and evaluation metrics.
