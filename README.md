# AI Engineer Handbook

This repository contains daily revision notes for AI Engineer interviews.

## Structure

- ML fundamentals
- Neural networks
- Deep learning
- Transformers and LLMs
- RAG and embeddings
- AI agents
- System design
- AWS
- Docker and Kubernetes
- MLOps
- Python and SQL

## Study format

Each topic file follows this pattern:

1. Definition
2. Why it is needed
3. Problem it solves
4. How it works
5. Mermaid diagram
6. Real-world example
7. Advantages
8. Limitations
9. Interview answer
10. Follow-up questions

## Purpose

The goal is not memorization alone. The goal is fast recall during interviews.
